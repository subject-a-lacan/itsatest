# jieshi: 给不具备读图能力的 AI agent 的说明

本文档用于解释 `papers/structure.png` 和 `papers/paper.png` 两张图片的内容，以及它们和当前任务、原始论文 `One-bit Hankel.md` 的关系。

注意：本说明只基于 `papers/One-bit Hankel.md` 和两张图片整理，没有修改任何代码。

## 1. 原始论文的核心思想

原始论文题目是 **One-bit Single-Measurement Spectral Compressed Sensing via Hankel Matrix Factorization**。它研究的问题是：只有单快拍、单测量向量的一比特观测 `y = csgn(x)` 时，如何重建一个谱稀疏信号 `x` 的缩放版本。

一比特采样只保留复信号实部和虚部的符号，因此原始幅度信息无法完整恢复。论文的目标不是恢复绝对幅度完全正确的 `x`，而是恢复与真实信号方向一致的缩放版本，并进一步用于频率或 DOA 估计。

论文主要利用两个结构先验：

1. **Hankel 矩阵低秩性**  
   谱稀疏信号由少量复指数/正弦分量叠加而成。把信号提升为 Hankel 矩阵后，该 Hankel 矩阵具有低秩结构，秩大约等于频率分量个数 `r`。

2. **符号一致性**  
   一比特观测 `y` 来自真实信号 `x` 的符号，因此估计信号 `z` 应满足 `Re(y ⊙ z) >= 0`。如果某些位置为负，说明估计信号和观测符号不一致。论文用 one-sided `l_p` 范数惩罚这些负值。

论文把这两个结构写成优化模型：既要让估计信号的 Hankel 提升满足低秩/Hankel 结构，又要尽量满足一比特符号一致性。由于直接 rank 约束很难解，论文采用 Hankel 矩阵因子分解，把问题变成关于低秩因子的非凸优化。

论文算法包括：

- **OSCAR**：基于 Hankel 矩阵因子分解的投影梯度下降算法。
- **Acc-OSCAR**：在 OSCAR 上加入 momentum/动量外推的加速版本。

重要区别：原论文中的 Acc-OSCAR 明确包含动量参数 `beta` 和外推步骤；如果当前代码没有采用动量，这属于对原论文算法的改造或简化，不应强行认为代码必须完全等同于 Acc-OSCAR。

## 2. `structure.png` 的内容

`structure.png` 是一张中文说明图，标题含义是：

> 图 6 知识-数据双驱动的单比特谱压缩感知网络

图片顶部文字说明：

本项目拟结合 **Hankel 张量低秩性** 和 **符号一致性** 这些结构知识，以及训练数据，提出基于 **深度展开网络** 的单比特谱压缩感知学习模型。根据采样方式不同，分别设计：

- 单快拍单比特深度展开网络
- 多快拍单比特深度展开网络

图中还说明了应用场景：

- **单快拍网络**：更适合高速移动目标检测、实时性要求较高的场景。
- **多快拍网络**：更适合慢速移动或静态目标监测。

### 2.1 图 (A)：单快拍单比特深度展开网络

图 (A) 展示单快拍情况下的网络结构。

整体流程如下：

1. 输入是经过采样/观测算子处理的一比特数据 `P_Omega(y)`。
2. 数据先经过 Hankel 提升算子，图中写成类似 `H_M(P_Omega(y))`。
3. 初始化层对 Hankel 矩阵做 SVD，并进行归一化，得到初始低秩因子 `U^0` 和 `V^0`。
4. 后面接 `K` 个展开层，图中画出了“展开层 1、展开层 k、展开层 K”。
5. 每个展开层都包含两个模块：
   - 梯度下降模块
   - 约束满足模块
6. 最后一层输出低秩因子后，通过 Hankel 伪逆/逆映射恢复信号，输出 `x^K`。

图 (A) 下方还放大画出了两个模块。

**梯度下降模块**：

- 输入上一层的 `[U^{k-1}, V^{k-1}]`。
- 先进行“梯度计算”。
- 再用步长 `eta_{k-1}` 做一次梯度下降更新。
- 输出中间变量 `[\hat U^k, \hat V^k]`。

这个模块对应原始优化算法中的一次梯度下降迭代。

**约束满足模块**：

- 输入 `\hat U^k` 和 `\hat V^k`。
- 分别送入两个神经网络模块，图中标为 `NN`，参数类似 `theta_U^k` 和 `theta_V^k`。
- 每个神经网络的输出与输入之间有残差连接/加法结构。
- 输出修正后的 `U^k` 和 `V^k`。

这个模块不是原论文 OSCAR 的普通投影步骤，而是把“满足结构约束”的过程学习化。它的目标是让迭代变量更快满足符号一致性约束和 Hankel 低秩结构。

### 2.2 图 (B)：多快拍单比特深度展开网络

图 (B) 展示多快拍情况下的网络结构。

整体流程如下：

1. 输入是多快拍观测矩阵 `P_Omega(Y)`。
2. 通过 Hankel 张量提升算子，图中写成类似 `H_T(P_Omega(Y))`。
3. 初始化层使用 Tucker 分解，并进行归一化。
4. 初始化输出多个因子，图中是 `L^0`、`R^0`、`V^0`、`S^0`。
5. 后面同样接 `K` 个展开层。
6. 每个展开层也包含：
   - 梯度下降模块
   - 约束满足模块
7. 最后通过 Hankel 张量伪逆/逆映射恢复信号矩阵，输出 `X^K`。

图 (B) 下方放大了多快拍版本的两个模块。

**梯度下降模块**：

- 输入上一层的 `[L^{k-1}, R^{k-1}, V^{k-1}, S^{k-1}]`。
- 进行梯度计算。
- 用步长 `eta_{k-1}` 更新。
- 输出中间变量 `[\hat L^k, \hat R^k, \hat V^k, \hat S^k]`。

**约束满足模块**：

- 对 `\hat L^k`、`\hat R^k`、`\hat V^k`、`\hat S^k` 分别使用神经网络修正。
- 图中每个变量都有一个对应的 `NN` 模块。
- 每个 `NN` 后面都有加法残差结构。
- 输出 `L^k`、`R^k`、`V^k`、`S^k`。

多快拍图里的核心变化是：从单快拍的 Hankel 矩阵低秩，扩展到多快拍的 Hankel 张量低秩，并用 Tucker 分解表示多因子结构。

## 3. `paper.png` 的内容

`paper.png` 是对图 6 的文字解释截图。截图中的主要内容如下。

第一段说：

如图 6 所示，迭代算法被展开为一个初始化层和 `K` 个展开层。其中，`H_M` 的伪逆算子 `H_M^\dagger` 满足：

`H_M^\dagger H_M = I`

`H_T` 的伪逆算子 `H_T^\dagger` 满足：

`H_T^\dagger H_T = I`

这说明图中的 Hankel 提升算子和伪逆算子是一对“先提升、再还原”的结构。单快拍使用 `H_M`，多快拍使用 `H_T`。

第二段说：

初始化层采用归一化谱初始化算法设计。每个展开层包含两个模块：

- 梯度下降模块
- 约束满足模块

在每个梯度下降模块后面增加一个约束满足模块，目的是使迭代变量快速满足：

- 符号一致性约束
- Hankel 张量低秩性约束

这样做是为了加速谱稀疏信号的重建。

截图后半段还说，接下来以多快拍单比特谱压缩感知学习模型为例进行阐述，单快拍采样下的模型构建方法与之相似。最后一句在图片中被截断，能看到的内容停在“基于优化问题 (20)，为多快拍问题分别设计以...”。

因此，`paper.png` 的作用是解释 `structure.png`：它明确说该网络不是随意堆神经网络，而是把传统迭代优化算法展开成网络层，并在每个梯度下降步骤后加入可学习的约束满足模块。

## 4. 两张图和原论文的关系

原论文提供的是优化问题和传统迭代算法基础，老师图片展示的是把这种迭代思想改造成深度展开网络。

二者的继承关系可以这样理解：

1. 原论文给出结构先验  
   核心是 Hankel 低秩性和一比特符号一致性。

2. 原论文给出迭代求解框架  
   OSCAR 使用初始化、梯度下降、投影/约束处理，Acc-OSCAR 进一步加入动量加速。

3. 老师图片把迭代算法网络化  
   每一次迭代被展开成一个网络层。原来手工设计的梯度下降步骤保留为“梯度下降模块”；原来用于满足结构约束的投影或修正，被改造成“约束满足模块”，并由神经网络学习。

4. 老师图片扩展了问题形态  
   原论文主要是 single-measurement/single-snapshot 的 Hankel 矩阵因子分解。图片中除了单快拍网络，还设计了多快拍网络，把 Hankel 矩阵结构扩展为 Hankel 张量结构，并用 Tucker 分解初始化。

5. 当前代码如果没有动量，不一定是错误  
   原论文的 Acc-OSCAR 使用 momentum。老师图片中的结构图没有画出明显的动量外推分支，也没有 `beta` 外推项；它主要强调“梯度下降模块 + 约束满足模块”。因此，如果代码采用无动量的深度展开层，可以理解为基于 OSCAR 思想的学习化版本，而不是完整复现 Acc-OSCAR。

## 5. 给后续 AI agent 的阅读建议

理解当前工程时，不要把代码机械地当作原论文 Acc-OSCAR 的逐行复现。更合理的理解是：

当前工程大概率是在原论文思想基础上，做了一个 **知识-数据双驱动的深度展开网络**：

- “知识”来自 Hankel 低秩性、符号一致性、谱初始化、梯度下降等优化结构。
- “数据”来自训练样本，通过神经网络模块学习如何更快满足约束或修正迭代变量。
- 网络层数 `K` 对应传统算法的迭代次数。
- 初始化层对应原论文中的谱初始化/低秩分解初始化。
- 梯度下降模块对应原论文的目标函数下降步骤。
- 约束满足模块对应对 Hankel 低秩和符号一致性的学习化修正。
- 如果没有 momentum，则更接近普通 OSCAR/梯度展开版本，而不是 Acc-OSCAR 的完整动量版本。

一句话总结：

这两张图说明，当前神经网络代码不是凭空设计的黑盒网络，而是把原始 one-bit Hankel 信号重建论文中的优化迭代过程展开为神经网络，并用可学习模块替代或增强传统约束处理步骤。
